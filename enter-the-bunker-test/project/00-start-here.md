# Join the Bunker: start here

**Account:** Join the Bunker, @jointhebunker (Instagram; TikTok and YouTube Shorts to follow)
**Series:** *Enter the Bunker*, a vertical short-form story series
**As of:** 21 November 2026, six hours after episode 1

## The show in one paragraph
A narrator invites viewers into a buried nuclear bunker with 100,000 beds. **Following gets you a bed; commenting picks your spot.** The counter fills as the account grows, and milestones change the bunker: lights at 1,000, air at 10,000, the door seals at 100,000. Beneath it all is B8, a floor that shouldn't exist, holding one bed that is already taken: **bed 0**. Each episode gives the audience one new clue, one thing to comment, and a roll call of real survivors.

## How to use this folder with Claude
Put these files in a Claude Project for the channel. Then any new chat starts out knowing the lore, the rules and the plan. When something changes (a decision, a new episode, new stats), ask Claude to update the matching document, so the folder stays the single source of truth.
