# Pixel Countdown Science — decisions

Made from a blank page. "Base" = the technique base, 16-bit Pixel RPG (pixel-rpg); "—" = new.

| Section | Base | Now | Why |
|---|---|---|---|
| Use / size | 1920×1080 landscape, 30–60 s | 1080×1920 vertical, 25–40 s shorts | The user posts vertical science shorts |
| §1 Essence | Story told through game systems (dialog, menus, saves) | The viewer counts along with one big hero object with a face; one fact per caption; ends on a CTA | The references' core grammar |
| §2 Resolution | 320×180 ×6 | 270×480 ×4 | Matches the references' chunky pixel size on a vertical frame |
| §2 Glow & 3D | No bloom, no real-time light | Dithered glow rings + low bloom on brightest tones; pixel 3D planes (mode-7) allowed | References glow (knuckle) and tilt into 3D (thunder fields) |
| §2 Setting & prop | — | The hero sits in a setting next to a measuring prop that moves on every count | References: cricket by a thermometer post, mouth, knuckle timer |
| §2 Hero objects | 20–34 px sprites + 32×32 portraits | One large hero (100–160 px) with its face on the object itself | References' central cute-face objects |
| §3 Colour | Palette = feeling; colour depth = time | One saturated mood ground per film; yellow reserved for numbers and key words | References' consistent highlight logic |
| §4 Type | Dialog box with portrait, typing text | Top captions, regular-weight blocky caps at 2× with a full ink outline, white + ink shadow, `*key words*` yellow; big yellow counter 3–5×; captions cut, never type | References' caption system |
| §5 Motion | 24 fps; game acting; mosaic/swirl transitions | 30 fps; the count is the clock; push-in/pull-back/split/flash; no dissolves | References' rhythm |
| §6 Camera | Side-scroll, battle view, overworld | Locked centre, push-in, pull-back, vertical tilt, split, pixel 3D tilt | References' camera set |
| §7 Sound | Chip score with echo + voice optional | No voice; tick per count, ambient bed, chip blips, one hard silence, chiptune end melody | References' audio (spectrogram: steady ticks, bed, blips, silence, melody) |
| §8 Native moves | Palette collapse, save files, level up… | Count along, countdown challenge, equation reveal, split verdict, reload timer, CTA return | References' recurring devices |
