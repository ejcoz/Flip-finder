# Say the Colour — treatment

Style: Pixel Countdown Science. 1080×1920, 30 fps, 42 s, English, no voice. Feel rules (STYLE.md §5), two sound layers (§7), built for an action (§10b).

| Action | The reason this film gives |

| Comment | Everyone reaches a level (1, 2 or 3) and can report it; the mascot fails once, which invites "I failed there too" |

The mascot from "How Rare Are You?" returns, so a series builds a recognisable character.

| 30–30.5 | — | Frame dims | **True silence** |
| 30.5–36 | READING IS AUTOMATIC / NAMING COLOURS ISN'T (STROOP EFFECT, 1935) | The colour words orbit the dizzy mascot | Impact + swell; backing returns softly |
| 36–42 | WHICH LEVEL / DID YOU REACH? (SEND TO A FRIEND. PART 2 SOON) | A 1 · 2 · 3 picker; the mascot winks | Home key; the colour notes as a tune |

Sound idea: each ink colour has its own note (red = C, blue = E, green = G, purple = B), so the run of right answers is the melody. Yellow is never used as an ink, because yellow is reserved for numbers and key words in this style.

## Facts and sources
- **The Stroop effect:** naming the ink colour of a colour word is slower and more error-prone when the word names a different colour (J. R. Stroop, "Studies of interference in serial verbal reactions", *Journal of Experimental Psychology*, 1935; reviewed by MacLeod, *Psychological Bulletin*, 1991).
- **"Reading is automatic, naming colours isn't"** is the standard textbook explanation (automaticity / speed-of-processing accounts). It is a simplification; researchers still debate the exact mechanism.
- No percentages are claimed. The film asks viewers which level they reached instead of saying how many people fail.
